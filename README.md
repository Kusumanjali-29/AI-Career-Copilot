# AI Career Copilot 🚀

AI Career Copilot is an AI-powered student career guidance web application designed to help students explore suitable career paths, assess their skills, and plan their learning journey.

## 🌟 Features

- 🎯 Career recommendations
- 🧠 Skill assessment
- 📚 Personalized learning roadmap
- 💼 Career profile exploration
- 🔎 Career and skill search
- 👤 Student login and registration
- 📊 Student dashboard
- 🌙 Modern responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design
